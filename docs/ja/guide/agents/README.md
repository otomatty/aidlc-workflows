# エージェント詳細

領域エージェントごとに 1 ページあります。担当領域、リードとサポートのステージ、読むナレッジ、協働の仕方です。全 14 体は、領域 11、レビュー専用 2、適応型ワークフローのコンポーザー 1 です。この索引は、ステージを進める領域エージェント 11 体です。

レビュー専用は、プロダクトとアーキテクチャを独立に点検します。コンポーザーは、適応型のステージ計画を提案し、組み直します。3 つの役割グループと、「狭い専門家 30 ではなく守備の広い 11」の考え方は [エージェントの章](../06-agents.md) です。frontmatter の契約、ツール許可リスト、比較表の全体は、Developer Reference の [Agent Reference](../../reference/agents/README.md) です。
